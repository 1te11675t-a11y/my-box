# 引越し箱（iPhone用）

引越しの段ボールに番号を振って、中身をiPhoneで記録するアプリです。
`プライベートタスク_モバイル/` と同じ作り（GitHub Pages に置いて、ホーム画面に追加して使うPWA）です。

- **データはiPhoneの中だけ**に保存されます。サーバーには何も送りません。
- **一度開けば圏外でも動きます。**
- QRラベルを刷って箱に貼り、標準カメラで読むとその箱の画面が開きます。

---

## 1. 使う順番

この順番だと、パソコンとiPhoneの間でデータをやり取りする場面が一度もありません。

| | やること | どこで |
|---|---|---|
| 1 | **ラベル**タブで `B001`〜`B060` を作って印刷する | パソコン（データは空でOK） |
| 2 | 段ボールに貼る | ― |
| 3 | 詰めながら、標準カメラでQRを写す → アプリが開く → 場所と中身を入れて保存 | iPhone |
| 4 | 引越し先で「あれどこ？」→ **箱**タブの検索窓に品名を入れる | iPhone |
| 5 | 開けたら ✓ を押す | iPhone |

**QRの中身は箱IDだけ**なので、中身を決める前にラベルを刷れます。ここがこのアプリの肝です。

---

## 2. 画面

| タブ | 中身 |
|---|---|
| 🗂 **箱** | 検索窓（中身・ID・場所を横断）＋グループ／場所の絞り込み＋未開梱／開梱済の切替＋並べ替え。右下の ＋ で追加 |
| 🔢 **ID** | QRが読めないとき、IDを直接入れてその箱を開きます |
| 🖨 **ラベル** | A4にQRラベルを並べて印刷します |
| ⚙（右上） | 書き出し・読み込み・全消去 |

- カードをタップすると、その箱の画面（＝編集画面）が開きます。表示と編集は分けていません。
- カード右端の **✓** で開梱済み、**↩** で戻せます。
- 消したり置き換えたりした直後は、下に出る「**取り消す**」で戻せます。

### 検索

「毛布」と入れると、**毛布が入っている箱**が出ます。ヒットした品名がオレンジで表示されるので、どの箱のどれが引っかかったのか分かります。

- ひらがなでカタカナが引けます（`まぐかっぷ` → マグカップ）
- 全角でも半角でも同じ（`ＴＯＭＯ` → TOMO-012）
- 品名だけでなく、ID・場所・メモも探します

---

## 3. 箱IDの付け方

**決まりはありません。**16文字までなら英数でも日本語でも構いません。

```
B001    B002    ...        ← ふつうの通し番号
妻-01   妻-02   ...        ← 人で分ける
寝室A   寝室B   ...        ← 部屋で分ける
```

IDの**末尾の数字を取った部分が「グループ」**として自動で扱われます。

| ID | グループ |
|---|---|
| `B012` | `B` |
| `妻-01` | `妻` |
| `TOMO-012` | `TOMO` |

事前に何も設定しなくても、使ったIDから箱タブの「すべてのグループ」の中身が勝手に増えていきます。
途中から `妻-01` を使い始めても、それだけで分類が1つ増えます。

---

## 4. QRについて

QRの中身は、このアプリのURL + `#箱ID` です。

```
https://<ユーザー名>.github.io/my-boxes/#B012
```

- **iPhoneの標準カメラで写すだけ**で、このアプリが開いてその箱の画面になります。アプリ内のカメラは要りません。
- **登録していないIDを読むと、そのまま新規登録の画面**になります。ラベルを先に貼っておく使い方は、これで回ります。
- 家族の端末で読んでも開けます（その端末にはデータが無いので、IDだけの空の画面になります）。

### 画面のQRを保存・印刷したいとき

箱の画面を下までスクロールすると、**白いカードに大きくQR**が出ます。

- **長押しすると「写真に追加」で保存できます。** スクリーンショットより余計なものが写りません。
- スクリーンショットでも印刷できます。QRは白地に黒で描いてあるので、**画面が暗いテーマでもそのまま刷って読めます**（ここだけ白くしてあるのはそのためです）。
- ただし画面の写真は解像度が上がりません。**まとめて刷るならラベルタブのほうが綺麗**です。1枚だけなら「このラベルだけ印刷」が使えます。

---

## 5. ラベルの印刷

**ラベル**タブで作ります。パソコンでこのURLを開いて刷るのがおすすめです（連番ラベルはデータが無くても作れます）。

- **連番で作る**：接頭辞（`B` / `妻-` / 何でも可）と開始・終了・桁数を入れます。一度に300枚まで。
- **登録済みから**：いま登録してある箱のぶんだけ作ります。場所の名前もラベルに入ります。
- **A4 1枚あたりの面数**：大6面（97×94mm）／中12面（65×70mm）／小24面（49×47mm）。
  段ボールに貼るなら**中12面**がちょうどいい大きさです。
- 点線は切る目安です。印刷の余白はA4で8mmに設定してあります。

## 6. データ

- 保存先は**このiPhoneのブラウザの中だけ**です。ブラウザの履歴やサイトデータを消すと、一緒に消えます。
- ⚙ → **JSONに書き出す** でバックアップできます。ときどき書き出してください。
- 読み込みは「**追加**（同じIDは今のを残す）」と「**置き換え**（全消去してから入れる）」を選べます。
- 別のiPhoneに移すときも、書き出し → 送る → 読み込み、です。

データの形（`boxes-YYYY-MM-DD.json`）：

```json
{
  "version": 1,
  "boxes": [
    {
      "id": "B012",
      "place": "寝室",
      "items": [{ "name": "冬用毛布", "qty": 1, "note": "" }],
      "priority": "later",
      "opened": false,
      "note": "上に載せない",
      "photo": null,
      "createdAt": "2026-08-31T10:00:00.000Z",
      "updatedAt": "2026-08-31T10:00:00.000Z"
    }
  ]
}
```

`priority` は `first`（すぐ開ける）／`normal`（ふつう）／`later`（あとで）です。

## 7. GitHub Pages に上げる

タスクアプリ（`my-task`）のときと同じ手順です。**別のリポジトリを新しく作ってください。**
同じリポジトリのサブフォルダに置くと、タスクアプリのオフライン用の仕組み（サービスワーカー）がこちらのファイルまで抱え込んでしまい、更新が反映されないことがあります。

1. GitHub の右上 **＋** → **New repository**
2. **Repository name** に `my-boxes` と入れて、**Public** を選び、**Create repository**
3. **uploading an existing file** から、このフォルダの中身を**ファイルのまま全部**アップロード
   （`index.html` `qrcode.js` `sw.js` `manifest.webmanifest` `icon-192.png` `icon-512.png` `apple-touch-icon.png`。
   フォルダごとではなく、**中のファイルを選んで**ください。フォルダごと上げるとURLが深くなります）
4. **Commit changes**
5. **Settings** → 左の **Pages** → Source を **Deploy from a branch**、Branch を **main / (root)** → **Save**
6. 数分待つと `https://<ユーザー名>.github.io/my-boxes/` で開けます

### iPhoneのホーム画面に追加

SafariでそのURLを開き、下の共有ボタン → **ホーム画面に追加**。
アドレスバーの無い全画面アプリとして開き、圏外でも動きます。

> `README.md` と `構成検討.md` は上げても上げなくても構いません（アプリの動作には関係ありません）。

## 8. ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 本体（HTML・CSS・JavaScript） |
| `qrcode.js` | QRを作るライブラリ（[qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) / MIT）。同梱してあるので、実行中に外部へ通信しません |
| `sw.js` | 圏外でも開けるようにする仕組み |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・色 |
| `icon-*.png` `apple-touch-icon.png` | アイコン |
| `構成検討.md` | なぜこの作りにしたかのメモ |
